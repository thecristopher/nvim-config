# Signpost

`lua/core/signpost/`: the sign every travel shows, the same for fog, door and curtain: the project
or branch you arrive at in spaced capitals between two gold rules on a dark plate that fades at its
edges, solid behind the letters so it reads over anything. Every travel lasts `DURATION` from
`core/signpost/actions`, names when the screen is `COVERED` and its `SIGN` window, and takes `{
on_covered, on_done }`: `core/repos` swaps the session behind the cover and the `grace` banner of a
first visit waits for `on_done`, `core/git` checks out the branch behind it. Without motion both
callbacks run at once.
