# Floats

Floats and menus are opaque (`winblend` and `pumblend` 0, which-key and the toggleterm float too):
any blend ghosted the code behind through their text. Only the effects that blend on purpose (fog,
banners, the boss, rest, phantom, satellite's bar) set their own. Every float wears the same frame
(`NormalFloat` and `FloatBorder` on `mantle`), the blink completion menu included, so it and its
documentation read as one piece, and in the command line it shows only the label
(`completion_columns`), since blink calls every command and path there a Property. `[d` / `]d` jump
without a float, tiny-inline-diagnostic already writes the message beside the line, and the float
`<leader>xd` opens names the source only when there are several (`source = "if_many"`).
