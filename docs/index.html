A Neovim config

ELDENTREE

A tree whose branches are worlds. Every day it wakes up in a different one, and the colors, the words, the sounds, the start screen, the way you travel and the way you rest all change with it.

GitHub Install Keys

A title screen, once a day

Block letters per franchise, on the first launch of the day and on every switch.

The start screen is an inventory

Elden Ring opens the Roundtable Hold. On Resident Evil days it is the STATUS screen.

Fighting your code

Banners land on commits, PRs, test runs and felled bosses. When you die, the code crumbles into rain behind the banner.

A game that keeps score

Everything below is counted from the work you already do.

Bosses

Three errors that linger bring the region's boss. Every fix lands a hit. :Boss

Bestiary

Every kind of error you clear is a foe felled, named from the world's enemies. :Bestiary

Ranks

Each run is ranked S to D on exit, counting only the time you were active.

Chronicle

Twenty weeks as a grid, lit by your ranks and your commits. :Chronicle

Feats

Twelve trophies that slide in as toasts and stay in a showcase. :Feats

New game plus

A year after your first day the cycle rises and the bosses come back carrying it.

Wrapped

Your year in one card: hours, ranks, your nemesis and your song, saved as a PNG. :Wrapped

Seasons

Halloween brings Resident Evil, December snows, New Year sparkles.

Expeditions

A quiet focus block that counts down and ranks itself. :Expedition

Your music, with its lyrics

Whatever Apple Music or Cider plays sits in the statusline, with the cover and synced lyrics a keypress away.

Under the costume, a full daily editor

Native LSP, Snacks pickers, git and PRs without leaving nvim, CI and review threads in the buffer, tests and debugging, and Claude Code dressed to match. Runs on macOS, Linux and Windows, and inside Cursor and VS Code.

Your own world

:Franchise new Silent Hill copies the template, :checkhealth eldentree lists what it still needs.

Your own style

Commit and PR drafts follow one style guide you can swap for yours.

Fast

Only the statusline and tabs load before the first frame, everything else one plugin per tick.
